# MTL-XF-014 — Telecom Customer Experience & Provider Performance Intelligence

**Mettelo Project Studio — Cross-Functional Delivery Series**

| Field | Detail |
|---|---|
| Client | Confidential UK Telecom Strategy & Customer Experience Directorate |
| Sector | Telecommunications / Customer Experience |
| Duration | 8 weeks |
| Recommended team | 6–8 |
| Sponsor | Customer Experience Director |
| Engagement | Simulated confidential-client engagement |

Customer attrition and service dissatisfaction are being discussed across broadband, mobile and pay-TV teams, but leadership lacks one consistent view that separates provider scale from complaint performance and persistent deterioration.

**Commissioned decision:** Which services and provider-performance patterns warrant intervention, and where should customer-experience teams prioritise root-cause investigation?

This is an end-to-end multidisciplinary engagement, not a dashboard-only exercise.
